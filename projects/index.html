A.E.G.I.S.

In development
AI-Enhanced Guidance and Intelligence System

A personal AI assistant in the spirit of JARVIS, built privacy-first. One self-hosted instance on my home PC holds everything (memory, skills, settings, and history), and it is never duplicated. My laptop is only a window into it, connecting over an encrypted private mesh, so nothing is reachable from the public internet.

Capabilities
  • One canonical instance: memory, skills, and settings live in one place
  • Thin remote client: the laptop shows the interface, every tool runs on the host
  • Remote access only over an encrypted mesh, behind a sign-in gate
  • Local interface locked to the PC itself
  • Always-on services that start automatically and recover from failures
  • Automated reports and messages delivered over Signal
